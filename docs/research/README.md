# Research

Findings that took longer to reach than they take to read — surveys, format
evaluations, and readiness assessments. Each one is a markdown file here (the
durable, greppable copy) and a designed write-up behind a link (the version to
send someone).

The rule for this directory: **write down what was measured, not what was
assumed.** Every number in here came from an API, a converter, or a test run on
the day it is dated. Where something is inference rather than evidence, it says
so.

**Every note carries its status in front matter** — `open`, `designed`,
`partial`, `built`, `blocked`, `superseded` — and
[`../ROADMAP.md`](../ROADMAP.md) is generated from it. A verdict written twice
is a verdict that goes stale in one place: this file's table is prose for a
reader, and the front matter is what the roadmap reads.

| 2026-09-04 | [Modules: adding a kind of thing, and taking it away again](2026-09-04-modules.md) | What it would take for a module — `@isocan/whiteboards`, `@isocan/documents`, `@isocan/sandboxes` — to add node types, tools, agent tools, inspectors, panels and whole sections, and be removed again. isocan already has three extension idioms (files, items with roles, the storage seam) and none is a module; the registries a module would fill are all closed and were **counted: 8 kinds, 6 tools, 5 panels, 17 actions, 13 slash commands, 139 verbs, 33 ops** — and the last dock panel touched **12 source files across three packages**, the mind map 7, because "the set of panels" is spelled five times and nothing reads a list. Five features in a fortnight added zero ops, which is what makes modules possible. The finding that makes REMOVAL safe is the data model: an item is a file with a mime, no op names a kind, so a missing module leaves files where tldraw (measured) throws. Two trust classes that must not blur: an extension is trusted like a collaborator, a module like the CLI you installed. Recommends removing before adding — the mind map into `packages/modules/`, Mermaid as the first node type, documents for the inspector and page slots, runtime loading for self-hosted homes, sandboxes last behind three named gates. |
| 2026-09-02 | [Google Docs on the canvas](2026-09-02-google-docs-on-the-canvas.md) | Can a Google Doc live on the canvas — embedded, linked, kept current by an agent? **Measured**: a link-shared doc's `/preview` and `/edit` come back with no `X-Frame-Options` and no `frame-ancestors`, so `isocan browse <doc>/preview` frames it today; anonymous markdown export works for a public doc, and the Drive API exports `text/markdown` (10 MB ceiling) with `changes.list`/`changes.watch` to know when a doc moved. | 26 Aug 2026 | [WYSIWYG on the stage](2026-08-26-wysiwyg.md) | How to edit a screen's text and properties without opening its source — and the finding that no off-the-shelf comparison covers: **the sandbox physics decide, and they were measured here**.
