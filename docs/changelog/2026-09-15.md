# 15 September 2026 — Design defaults that survive the next screen

Design-partner phase 3 makes creation, source reads, audits and Files notices use
one governing-system result. Group, ancestor, canvas and permitted inherited
systems keep their scope. Explicit exemption removes the requirement to write a
system; it does not hide an incumbent. The widened request binding is negotiated
with both daemon generations, including an actual archived prior-daemon probe.

Three authored native references demonstrate different compositions: receiving
stock, reading a field guide, and reserving a place in a synthetic repair
workshop. Their actual tasks, states, keyboard behavior and mobile layouts were
walked in Chrome. A second screen reads browser-authored accepted treatments
through a distinct CLI agent and preserves its measured controls. A constrained
repository extends its real component and tokens against its existing server.
These are engineering and craft-reference results; the independent design-quality
and partnership study still belongs to phase 7.

Verification changed the implementation. Malformed documents must be validated
before their retry journal becomes immutable. An accepted receipt survives a
later read failure, and a generic operation ID cannot substitute for its actual
payload and actor. Different governing documents need archive-before-close
recovery. Running HTML in its native origin did not prove the embedded preview:
actual opaque frames exposed blocked native forms and a history navigation error.
The preview now keeps its isolated origin, working local focus/navigation and
honest temporary-state labels. Legacy areas cannot guarantee a scoped add without
possible resize/shift acts, so the library requires groups for new creation.

Integration also repaired the incoming bench release failure: seven unused
implementation exports now remain local, with its actual CLI/core/web behavior
and declaration output preserved. The existing API ceiling stayed in place.

The final source and complete local journey passed full fast, typecheck, build
and strict emulator gates. The initial entry remains 722,646 bytes under the
unchanged ceiling. Phase 4 is next: real alternatives and a safe adopted decision.
