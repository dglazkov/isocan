# 22 October 2026 — motion, from a still drawing to a movie

Three phases of [`motion`](../projects/motion/) landed in one day, behind the
`motion` experiment, each verified independently and pushed whole.

**Phase 0** (`29bd7a62c`) put a motion engine in `@isocan/core/motion`: our own,
written to the shapes of rossark0/rossark-motion-skill (MIT, credited, no code
ported), with every value a pure function of `t`. That purity is the design's
spine — the preview, the scrubber and every exported frame are the same
calculation — and it was proven in headless Chrome: the frame at 1.2 s
pixel-identical twice and after a jump to 0.3 s. The document carries the engine
as `createMotionEngine.toString()`, so whatever toolchain compiled core is the
text it runs; no twin to drift. Adding a CLI module now meets three ceilings at
once, and motion raised two of them by a dated sentence each rather than
reshape module loading.

**Phase 1** (`c638a764f`) made the movie. The render page reads the motion blob
into an inert DOM and drives it with core's own engine — never the sandboxed
frame's pixels, never the document's copy — encoding with WebCodecs H.264.
`isocan motion render` opens the same page headless, so the two surfaces cannot
drift: decoded frames sit within 2.2 of the page's own pictures, each nearest
its own, and the web's hidden-frame path decodes to the CLI's exactly. The
design's item-only route was wrong (an item names no canvas) and was corrected.
Modules gained a way to run isocan's own `scripts/*.mjs` (module API 0.2.11).

**Phase 2** (`e59d061a0`) gave the browser its doors: *Animate…* on a selection,
a scrubber below the stage, comments pinned to a moment that scrub the player
back, *Refresh from sources* and *Render movie…*. A real Codex turn on the exact
ask the web sends first *printed* `isocan motion new …` instead of running it —
"answer with" read as "reply with this text" — something the scripted stand-in
could never have shown. The ask and the guide now say RUN, and a second turn
wrote and ran the spec.

[`motion`](../projects/motion/) itself.
