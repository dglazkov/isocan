# 25 September 2026 — The frame budget, measured again

The day's weight was performance, measured on a real canvas for the first
time since 29 August. It found that the ordinary thing — somebody else working
on the canvas you are looking at — was the slow one, and that the tool the
repository used to see inside its own bundle had been wrong for eighteen days.
Around it: the wireframes journey caught up with its own design, the judge's
roadmap note stopped contradicting itself, and a cleanup audit became a
project.

## The instrument first (`38a9f701`)

`scripts/bundle-what.mjs` attributes the entry chunk's shipped bytes to their
sources through the sourcemap, and it walked `sources` by each segment's
fourth field — the original column — instead of its second. The table it
printed had the shape of an answer, and on 8 September it had "corrected" the
architecture review's reading of the chunk, which was right. Read properly the
entry is 43% web and 29% core, and the canvas is its largest part.
`test/bundle-what.test.ts` holds the field to a hand-built map; lesson 100 is
the rule: an instrument gets a known answer before its first reading is
believed.

## A collaborator's drag froze everybody else (`2016c2bc`, `cb9308c1`)

A frame census — a daemon, 250 notes, headless Chrome at 4x CPU — with a
third gesture nobody had measured: another client moving one item while this
browser only watches. Every frame took half a second. Two sprint hooks that
every item calls, and every note's markdown renderer, subscribed to the whole
canvas, so each operation re-rendered every item and re-parsed every note:
15,455 renders and 15,000 parses for 60 moves. They now ask for the boolean,
the list or — for a note whose links are all external — nothing. Behind them,
the `#` roster rebuilt its names on every operation (so every comment
re-parsed) and de-duplicated them quadratically. Remote drag p50: 500 → 33 ms.
Render counts guard all of it.

## Zooming re-rendered every item (`4dba76f7`)

Every item read the raw zoom level. Its continuous chrome — the counter-scale,
the row width, the name's room, a mark's size — is CSS now, against the
world's `--scale`; the six threshold decisions are one selector packed into
bits, so an item re-renders when one of its own flips. 7,500 renders a zoom
became 1,250, p90 83 → 50 ms, and a browser comparison of 1,920 chrome element
states at ten zoom stops found no difference. Pinning the world layer with
`will-change` was measured and made it worse.

The findings, the numbers and what was not chased are
[the research note](../research/2026-09-26-frame-budget.md); the census is kept
as `scripts/frames.mjs`.
