# 7 September 2026 — Idle is the measurement, and silence gets a deadline

## Every open canvas was burning a third of a core

The 6 Sep freeze had two halves, and both were found by measuring rather than
reading. **The CPU half** (`0ca0676`): `useCommands` returned a new array on
every call, `useCanvasTools` listed it as an effect dependency and called
`setTools` — a render loop on every open canvas since 6 Sep. A canvas nobody
was touching profiled at 68% idle; fixed, 100%. Neither commit that built it
was wrong on its own (one made the return unstable, the next day another file
consumed it), and `exhaustive-deps` checks that dependencies are complete,
never that they are stable. So `stablehooks.test.ts` requires every exported
hook to return a primitive, a memo, or an allow-listed value with its reason;
the sweep found four more loaded guns. Lessons 36 and 37: reading the code had
produced five wrong diagnoses over three sessions, and a six-second profile
named it in one. When the symptom is slow or frozen, profile at rest first.

That lesson then became a journey, because a guard nobody runs is a wish
(`7e3bfba`): `idle-at-rest` profiles four seconds of an untouched canvas, fails
past 15% busy, and proves its own instrument on every run by burning the main
thread on purpose. A push-time goal for it was tried and reverted the same day,
because `test/journeys.test.ts` forbids a browser walk per commit; the reason
now sits in the reviews README (`3179478`).

**The memory half** (`5f2604e`). Subframes at 713 MB, 940 MB and 1.3 GB. The
earlier fix kept a document live once seen, which bounded nothing; now leaving
the screen releases it after a grace period, a hidden tab counts as off screen,
and the viewport — which had no gate at all — stands down screens, sites,
canvases and live Docs. Heap −30% locally; the gigabyte freeze itself was never
reproduced headless, and the entry says so. Background tabs also stopped
polling the daemon, and come back by reading at once rather than showing an
answer a period old (`34d0030`); held Space and Z are released on blur, as the
pen already was.

## Agents you can trust (#197)

The question behind it: naming an agent produced a reply or silence, and
silence looked the same as thinking.

- **The fold** (`6c8c862`). In core: asked → picked up → answered, or past a
  bound, *nothing answered* — split by whether an rc is parked, because a
  broken agent and nobody home want different next moves. Who counts as
  summoned comes from `reasonFor`, so a receipt cannot promise a wake the rc
  will not perform. No op: a receipt is true of a viewer, not the canvas.
- **A deadline** (`ec5728c`). "Fable was woken — waiting…" now ages into "woken
  45s ago and has not picked this up". A first cut read `activity.threadId`,
  which the protocol forbids; the fixtures had been built the same wrong way.
- **The roster says how long ago it heard** (`7ad7c24`), and an answerable
  agent's dot is filled so it stops looking like a merely enrolled one.
- **The queue can fail** (`7b5f35b`). 26 findings sat unanswered six nights
  while the entry chunk grew 100 KB. A finding unanswered for three days now
  reddens a commit — installed as a bound because the queue had just been
  drained to zero. The parser asks whether somebody *decided*, so a qualified
  `unanswered — …` cannot slip past: a guard against neglect fails closed.
- **A question asked six nights is not six findings** (`4fa0623`): `askedAgain`
  lists questions asked three or more nights, which want a guard rather than
  another answer.

And a real bug behind an rc flake (`437cbaf`, `722af44`, `1773ce5`): an
enrolment landing in the rc's startup window was in neither the opening roster
nor past the tip, so the rc printed "answering on X" and never answered. The
roster is now reconciled every lap, adopting *and* claiming. Three fixes, each
real and each insufficient alone; no deterministic test, and the commits say
CI decides.

## The size gate asks instead of blocking

Seven ceiling raises in two days, every one deliberate, was the finding
(`2b69ecf`): a bound edited that often is edited without being read. A jump of
20,000 bytes still stops the build; a creep becomes a persona finding to answer
within three days. That needed the reports on `main`, so persona PRs now merge
themselves when confined to `docs/reviews/`, and a repeated bound-finding is
one question, re-asked only if the number worsens 10% from the smallest value
anyone accepted.

## Grounds, cursors and the menu that holds them

Each ground now gives everyone a cursor in their own colour — sparkle, fish,
summit flag (`990062e`); a rocket at 18 px is an arrow. A canvas can stand on
your own picture (`e1f5f50`, #204 phase 2), with gc taught first that a blob a
property names is in use (`83d626f`). Background became a submenu showing the
set rather than a row that cycles (`3dc0734`), the app's first nested menu,
which keeps itself on screen (`553c2d0`). Prompts for painted grounds and
cursors were written for an artist (`d1d111f`, `f70049d`).

## Smaller

Touch: one finger pans, two pinch, about the point under the fingers
(`5ad7e68`); a phone no longer scrolls the front page sideways or overlaps the
minimap and zoom row (`cffeaf6`). `format` became `tidy`, `align` got a web
submenu, and both old names stay as aliases (`10d83e8`). `isocan start` is an
alias for `serve` (`be7def4`). Holding H or T borrows the tool instead of
bouncing (`619824a`). Archive now hides from the switcher too, and a nested
gate that made archiving a one-way door was split (`a950f86`). Clicking a
message's date folds it (`ea12371`). The hover outline survives zoom, and a
kind mark returns when chrome hides (`23aaa06`), never below 9 px (`32deb5f`).
The switcher moved into the ··· menu with ⌘O, and the caret went (`ec87835`,
`920b61f`). Research only: semantic zoom (`c3518c0`), custom grounds and small
personas (`f9bac80`), i18n and analytics (`5e4a1be`). Housekeeping: a ceiling
raise (`3f16f4b`) and a `see:` fix (`09a7da0`).
