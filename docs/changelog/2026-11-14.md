# 14 November 2026

Exact phases 2 to 8, conducted one after another, each verified and pushed
on its own.

## Live frames, every host, time, storyboards

- **Live, and pointing at lines** (`c71f54877`). On a loopback home a screen
  can go Live through `scripts/exact-live.mjs`: the dev loop, a frames proxy
  and a token-gated API on 127.0.0.1, paired once with a one-use code. The
  shell owns the door and keeps it shut unless Live frames is ticked; shut
  means no request at all. Alt-click names the Contract line.
- **Every host, and Drive mode** (`d325191cb`). Captures on the web, a
  dedicated iOS simulator named by UDID (never a booted device) and macOS,
  through Exact's own driver; a device wall per route; any screen driven from
  the canvas, through the canvas when Live frames is off.
- **Time and state** (`35bbcb8e2`). `isocan exact film` records an
  interaction against Exact's deterministic clock into a scrubbable strip,
  with state per frame from a second cold driver; the same inputs give the
  same bytes.
- **Tests are storyboards** (`dbd60baeb`). Each `test` block is a storyboard
  that runs per host from the canvas or the CLI; the verdict and its words
  stay Exact's, and each run is the storyboard's next version.

## Agents propose, and a person ships

- **Agents propose** (`1aa52c64f`). An enrolled agent pairs at `propose`
  scope; its token and style edits are held on Exact's wire and pictured
  before and after on every device, landing only on a person's Keep.
- **Ship** (`ad798d9ce`). A release lane from `app.json`'s `deploy`. Prepare
  (an agent may) runs Exact's dry run and hashes the origin either side, so a
  card can say nothing was uploaded; Ship, Promote and Roll back are a
  person's, refused for an agent on the CLI and the canvas alike. On the iOS
  Simulator the running app showed a shipped text change 6.3 s after the
  release was written. Its release run went red on an unrelated flaky test,
  fixed on 15 November.
- **Write is the machine owner's to grant** (`5e55af289`). Being allowed to
  edit a canvas no longer means write access to someone's running app: only
  the person whose machine runs the dev loop, or someone they grant, writes.
- **Teams and hosted canvases, in part** (`d79cde243`). A teammate pairs
  read-only through Exact's relay (proven against a relay on this Mac) and the
  wire refuses their drag, proposal, Keep and ship; a viewer sees captures
  only. Hosting the relay for isocan.io waits on a person.

## A blank page through the relay

The teammate's relayed page was blank because Exact's relay gateway read
minified `{0:0}` as an address (a lone `0` parses as 0.0.0.0) and rewrote it.
A one-condition fix with a regression test, proven on a clone, went to the
Exact team as a single diary entry (`63dc62d43`).
