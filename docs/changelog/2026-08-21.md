# A vocabulary for asking

**2026-08-21** · 24 commits · 211 files · +6,970/−4,372 · Dimitri Glazkov, Dion Almaer

Slash commands arrive — work a message can ask for — along with the design system, the help panel, and a layer scale that fixed four bugs of the same shape. The agent guide moved inside the CLI.

## Slash commands

- Typing `/` in any composer opens a menu; picking one posts an ordinary comment. **The web app never runs a command** — it writes down what was asked and an agent does the work, which is why `isocan comment add "/format …"` is the identical act.
- A command's body IS a skill. Three shipped, then more: `/format`, `/variation`, `/grill-me`, `/help`, `/design-audit`, `/design-system`, `/skill`, `/cancel`, and four ported from Studio.
- `/format` is a real layout in core, applied as one `items.move` — one undo, and a fixed point.
- `isocan command add --from <owner/repo/path>` fetches a published skill, PRINTS it, and installs nothing until `--yes`.

## Design as something checkable

- The design system is an item on the canvas — later a DESIGN.md — with typed tokens, a CSS emit, and a linter that computes contrast rather than judging it.
- `/design-audit` with seventeen named tells, each stating how to spot it in the source.

## The layer scale, and three bugs of the same shape

- `.toolbar` had `z-index: 20`, which makes it a stacking context — so its popovers at 30 and 40 were only competing with each other inside the bar, and the panel at 25 won.
- The same shape hid the identity menu under the trash panel, a beacon card under the favourites bar, and the minimap under a left panel.
- A test now fails the build on any z-index over 10 that does not come from the scale.

## Also

- A rename reaches what you already said: names resolve through the registry, so "Dion 2" stops speaking in old comments.
- Hold P and the whole sketch is one drawing, however long you take between strokes.
- `?` opens a panel listing every key the canvas answers to, from a list in core that a test checks against the code.
