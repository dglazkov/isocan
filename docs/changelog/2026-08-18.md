# The Pen, the radar, and the directory

**2026-08-18** · 12 commits · 122 files · +4,821 · Dimitri Glazkov, Dion Almaer

Ink arrives as a first-class item — an SVG, not a new op type — along with the edge radar for what has gone off screen, a foldable minimap, renaming, and the decision that a directory is a project.

## Drawing

- **The Pen (P)**, in your identity colour, with the ink well beside the rail. A drawing is an `item.add` whose blob is an SVG, so `ls` lists it and the CLI can download a real `.svg`.
- Ink is stored in WORLD coordinates: the SVG's viewBox is the drawing's world box, which is what makes it sit exactly where it was drawn at any zoom — and what later made merging exact.

## Finding things

- **The edge radar**: bars around the rim for items that have panned out of sight.
- A foldable minimap, renaming with filename collision handling, and ⌘-arrow spatial navigation.
- **A files panel**: the canvas as a directory, grouped by kind.

## Scope

- "The directory is the project" and "where you stand is the scope" — on call retired. A `.isocan/project.json` marker binds a directory to its canvas, nearest wins, like `.git`.
