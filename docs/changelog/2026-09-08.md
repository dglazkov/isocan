# 8 September 2026 — The canvas decides, the repo keeps

## Six systems, joined (#206)

Dion asked how the project's own machinery fits together. The research
(`217998b`) found nothing missing and nothing joined: personas measure, the
queue collects, lessons remember, research plans, evals grade, the board
displays — and nothing checks that what any of them declares is what happens.
The live proof was `design-auditor.md` declaring `trigger:` twice, so YAML ran
it at 08:23 while the 08:43 line above sat dead. The spine of the design is one
rule for five kinds of row — *derived, or decided, never both* — and one answer
to the "two homes for one fact" problem: **the canvas decides; the repo
keeps**. A click emits a commit, so the guard reading `docs/reviews/*.md`
never needs a network, and every decision lands in git with an author. The
code says `docket`, because `ledger` was already taken twice.

Then five phases in a day:

- **Phase 1, cadence observed** (`1efd500`). `trigger` was read by two things
  and both only displayed it; the workflow ran every persona on one hard-coded
  cron. Three of nine were wrong: the duplicate key, `market-researcher`
  declaring nothing while writing a page nightly, and `journeys` declaring
  Mondays. `scripts/cadence.mjs` reads the raw front matter because the parser
  silently keeps the last key. Making `trigger` load-bearing was deliberately
  left out: a filter that got "is it due" wrong would stop a persona silently.
- **Phases 2–3, a finding is answered by reacting to it** (`1f04f85`). One item
  per *question*, not per nightly row, so the docket does not silt up. ✅
  accepts, ❌ rejects — no new op, since `item.react` already carries who
  decided, shows disagreement, and undoes. Both marks is not a tie to break;
  it stays open. Walked end to end on a real canvas, which caught two things
  reading could not, including that the canvas handle could not remove an
  item.
- **Phases 4–6** (`cec25ce`). ✋ claims a card — canvas-only, because work in
  flight is true this afternoon and false tomorrow, while decisions belong in
  git. `scripts/decisions.mjs` derives `docs/decisions.md` (36 decisions, 47
  lessons) rather than adding a fifth hand-kept list. Trust is folded per
  question, and a persona nobody has answered reads `—`, never 0%. Phase 7
  waits on a secret only Dion can add.
- **Journeys go nightly** (`d8f5ac6`). A weekly walk meant up to seven days
  before a broken screen was noticed. The cadence reading had also only opened
  `persona.yml`, so it invented drift for `journeys`; it reads every workflow
  now and the ratchet is 0. Its negative control had asserted a real mismatch
  *exists*, so it would have failed the moment the bug was fixed.

`decisions.mjs` found something the moment it ran: `lessons.md` had three 16s
and several other duplicate numbers, and citations had already split across
them. Every first occurrence kept its number and duplicates took the free
ones, leaving 1–47 with no holes (`a43abbf`).

## Flakes, measured instead of re-run

"The flakiness keeps on going" (`dbe1b75`). Six clean runs: one failed after
its assertion passed, on `ENOTEMPTY` removing a scratch home. 140 `rm` calls
across 99 test files had no retry, while two scripts had used
`maxRetries` for days. 1 failure in 6 before, 0 in 12 after.
`test/teardown.test.ts` holds every file to it; `scripts/flakes.mjs` names the
flake set by running an unchanged tree N times. Lesson 38. Chasing a later red
found its cousins: `contentauth`'s forged signature was the real one one time
in 64 (lesson 39), and `rc.test.ts` left parked rc processes alive across runs
— which the retry had made quieter. Lesson 44: when a fix quietens a symptom,
ask what the symptom was reporting. `direct.test.ts` stopped hard-coding a port
that `stopDaemons` would kill whoever held (`a8e67a5`).

## Grounds from an artist

Seven tiles arrived and four shipped (`04b6cc7`). Farm and desert join; ocean
and mountains become the pictures the prompts were written for. The space tile
showed a seam laid 2×2, so galaxy kept its generated starfield, which was then
given colour, depth and nebulae with legibility asserted from the component's
own tables (`323c62f`). "png vs jpg" turned out to be seven JPEGs, three
misnamed (`98fe79b`). A canvas on your own picture can now choose a pointer —
drop, heart or crescent — chosen and never uploaded, because an image cannot be
tinted with each viewer's colour (`594f0be`). Two chrome fixes followed from
grounds the app cannot predict: the top fade now uses the ground's own token
(`c810b9c`), and menus are opaque so a submenu over a starfield keeps its hover
(`e10892c`, lesson 48). The grid that four places claimed returns under a
pinned ground never did; the comments and CLI help were corrected and a test
with nine mutants holds the stacking (`db0a0b9`).

## Half the first visit was one import

`scripts/bundle-what.mjs` attributes bytes to sources, and showed the entry
chunk was 51.5% `@isocan/core` (`3a09fb9`). One `import * as core` in
`runtimeModules.ts` pinned every export; fetching it inside the guard that
already skips canvases without runtime modules took the chunk 699,999 →
635,728, under the 640,000 goal for the first time.
