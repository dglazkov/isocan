# 27 September 2026 — Machinery that was only a paragraph

Three pieces of housekeeping, and each found that the thing everybody believed
was not quite the thing that was true. A rule in AGENTS.md had no program
behind it. A next step in a research note rested on a wrong reading of a
profile. And a week of "flaky" tests turned out to be one machine asked to do
twice what it could.

## The changelog queue drains itself (`5b817c27`)

AGENTS.md has said since 9 September that machinery owns the changelog
queue: a draft unmerged after three days is merged as a draft, and a PR whose
day somebody already wrote on `main` is closed by its own run. Nothing
implemented it. The 22 Sep draft sat open five days.

`scripts/changelog-drain.mjs` is now the workflow's last step, run every night
whether or not the day had commits. Its decisions are one pure function, held
by a test. It closed #358 for real on its first run, because the 26th had just
been written by hand. #347 was closed by hand: the 23 Sep page already says the
22nd has no page of its own, and merging the draft would have contradicted it.
The merge path first runs on CI once a PR reaches three days.

## Zoom's worst frames are not markdown (`483e51e0`)

The frame-budget note's next step was a parse cache: zoom's p99 read as notes
remounting and re-parsing. The cache was built and measured three runs against
three, and zoom p99 did not move (150/167/150 → 150/150/167 ms). The census now
reads Chrome's Long Animation Frames entries. The worst frames are ~100 ms of
script inside the **wheel handler** plus ~40 ms of style and layout: React
rendering every item synchronously when all 250 cross a threshold together.
Zustand's selectors go through `useSyncExternalStore`, which React never
defers, so what comes next is a design call rather than a measurement. The
cache stayed for what it does do: the remount parsing after a zoom went from
~410 ms of CPU to 3 ms.

## The deep lane stops timing out (`7ac1d7b8`)

Seven of eight deep runs that week had a timeout, a different file each time,
every one passing alone. A deep file keeps two processes busy, so one worker
per core put the machine at about twice its cores. At half the workers, every
test ran about twice as fast, the wall clock did not change (373 s), and
nothing failed — twice, the second time under a load average of 30. No limit
was raised. Beside it, `prune.test.ts` stopped spawning fourteen processes a
case to build its ground (7 s → 2 s), and the lane detector learned that an
MCP stdio transport starting the binary is a spawn, which moved a 7–30 s walker
out of the fast lane where it had been timing out. Lesson 101.

## The cleanup walk, all seven phases (`0c58db8a` … this page's last commit)

The 25 Sep audit's 91 findings, walked by the conductor in one day, each fix
landing with a guard seen to fail without it. The audit ran 106 commits
earlier, so each phase was re-checked against `main` first; three findings
had already been fixed by the frame-budget work, and several turned out
worse than written.

- **Phase 0** (`f49b418c`): `pr.yml` ran the suite whole under a 20-minute
  limit that runs were hitting; four shards now, slowest 8 minutes on a real
  PR. The red on every bot PR is a zero-job run GitHub never executes.
- **Phase 1** (`8a0493ae`): five ways one input ended a process or the page —
  an oversized WebSocket close reason, unhandled rejections in the upgrade
  handler and roster timer, a badge error outside the dial's try, an ACP
  adapter with no error listener, and a scrub to before a deletion that drew a
  blank page. Every item now draws inside its own error boundary.
- **Phase 2** (`bac63911`): an in-app canvas switch wrote the new canvas's
  seen-mark at the old one's head, and ink could follow you to the next canvas.
  Leaving now takes a canvas's ink to that canvas.
- **Phase 3** (`0dd8b242`): another person's cursor re-rendered every item;
  the census's new `cursor` gesture went from p50 50 ms to 16.7 ms.
- **Phase 4** (`d0fac911`): `isocan canvas shot` and deck export failed on
  every install; the release now bundles them and refuses a tree with an
  unresolved import (8 on the old `#release`, 0 on the new one).
- **Phase 5** (`6123848e`): copies agree or are gone — the talk resampler that
  wrote a zero once a second moved into core, one filename rule
  ("Crème brûlée" → `creme-brulee`), one mime table, one `ago`, and every CSS
  guard reads every stylesheet.
- **Phase 6**: the sweeps, each ending in a ratchet — `noUnusedLocals` and
  `noUnusedParameters` on, no dead CSS, `registerRoutes` 6,009 → 4,690 lines,
  one CLI-spawn helper where there were 71, and the root `test/` typechecked.

The entry chunk ended at 700,901 bytes, 120 under where the walk began
(701,021), without its ceiling moving once: each phase that cost bytes paid
them back.
Two process lessons went into the conductor skill: a red check that restored
from an index a failed `git add` had left at HEAD, and a walk that inherited
the repo's canvas binding and wrote to its canvas on isocan.io (removed, with
Dion's OK).
