# The day it learned to be installed

**2026-08-16** · 37 commits · 181 files · +6,732 · Dimitri Glazkov, Dion Almaer

Almost none of this is features. It is the day the thing became something a stranger could install, run twice, and share a machine with — plus themes, and a projected live site.

## Install, and the failures that only happen to other people

- "The install that unpacked to nothing" and "the links that broke every second install": `main` installs an empty directory, which is why the release branch exists.
- "The daemon that outlived its build" and "the daemon you just started is the one serving" — version skew between a running daemon and the copy you just pulled.
- "Two parties share this machine" and "a nameless home names itself": two people, one laptop.
- "Tests that restart a daemon have to stop it too", and "nothing a test run starts may outlive it".

## What people see

- **Light, dark and system themes**, resolved before first paint so nothing flashes.
- **Project the running app, not a picture of it** — a live localhost site as an item.
- **Entering an item hands it the wheel**: double-click to scroll and click inside a projected page.
- A minimap dot and a camera on a tether; presence that narrates itself.

## The bug with the best name

- "A PNG that refused to be dropped, and said nothing" — every macOS screenshot carries U+202F before AM/PM, which throws in a header value before a request is ever made. Filenames travel percent-encoded now.
