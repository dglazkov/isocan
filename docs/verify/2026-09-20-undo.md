# Undo, in both doorways

**Status: `unverified`.**

**What you need:** whatever you needed for [the voice walk](2026-09-20-voice.md),
plus the web app for part two. Ten minutes.

**Why this page exists.** Until 20 September there was no `undo` tool at all,
so asked to *"undo that"* the model invented an inverse move — which demos
beautifully and is wrong, because it records a second change rather than
retracting the first. The fix was confirmed by watching **which tool the model
asks for**. What was never watched is the daemon actually retracting, or the
browser dialog saying it cannot.

---

## Part one: the standing harness retracts

1. With the voice agent running (steps 1–3 of the voice walk), **move a card
   yourself** with the mouse. Remember which.
2. Ask the agent out loud to move a *different* card.
3. Say *"actually, undo that"*.

**You should see:** the agent's move come undone, and **your** move left
exactly where it is.

**Then check the log rather than the screen**, because this is the half that
looks the same either way:

```bash
node packages/cli/bin/isocan.js log --json
```

**You should see:** the last entry marked as an undo of the agent's move — NOT
a second `item.move` back to the old coordinates. If it is a second move, the
tool is being skipped and the model is improvising again.

## Part two: the browser dialog declines, in words

The in-app voice dialog is a different surface from the standalone page, and it
**cannot** undo: the module host it writes through has no retract, and widening
that is a versioned decision nobody has made.

1. Open the voice dialog inside the web app.
2. Ask it to move something.
3. Say *"undo that"*.

**You should hear:** it say plainly that it cannot undo here, and suggest you
undo yourself.

**You should NOT see:** the card move back. A compensating move is the exact
failure this refusal exists to prevent, and the tool's description tells the
model so in as many words — which is a request, not a guarantee. **This step is
the one most likely to fail**, because it depends on the model honouring
prose rather than on code refusing.

---

## What this walk does not cover

- **Redo.** It exists in the CLI and is not exposed to either voice surface.
- **Undo of anything but a move.** A delete or a rename should retract the same
  way, and nobody has tried.
