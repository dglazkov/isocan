## Surface accounting

No new operation or CLI verb is needed. The existing inbox and seen commands
now use authoritative per-canvas routes; shared core addressing and unread
sequence rules serve both clients. Private visits stay outside the operation
log. The existing agent-guide entries remain accurate. README describes the
new browser doors; CLI/HTTP tests and the actual browser walks prove them.

## Trajectory

- **2026-09-13** — A local replica intentionally retains content after remote
  withdrawal; the existing seen route forwards to one home. A client-only
  inbox would combine stale content with incomplete marks. The continuation
  therefore asks each authoritative home through one shared API assembly.
- **2026-09-13** — Aggregate routes do not inherit per-canvas refusal guards.
  Check admission, takedown and operator refusal before reading content or
  marks; a retained replica and a badge awaiting sweep cannot bypass them.
- **2026-09-13** — Targeted and aggregate mark reads can overlap during
  identity recovery. Share one repair, but never let an explicit claim await
  the repair that is waiting for that claim. The existing ten re-badge
  regressions exposed and now cover that cycle.
