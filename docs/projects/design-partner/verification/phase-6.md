## Findings that changed the implementation

- An actual browser-authored brief includes an actor DTO with an extra `key`.
  A structural TypeScript type did not make it a valid closed saved packet.
  The reader now explicitly projects public attribution; saved validation stays
  strict. The first independent context probes preserved this failure.
- A recommendation is not a chosen direction. The first projection printed only
  the recommendation. The corrected packet and readable view retain the accepted
  option's title, hypothesis, tradeoff and authority separately from the original
  recommendation, without inventing a human reason.
- Completing a human-corrected brief gives the completion a new author; it does
  not change who supplied its facts. Currentness now verifies the exact canonical
  completion edge and actual original attribution. Substantive completion patches,
  forged authors and missing original source evidence cannot pass that exception.
- An open view originally stayed current after a teammate changed its source.
  It now rechecks the original capture through canvas changes and visible polling,
  survives responsive remounts, and requires explicit refresh to replace it.
- Final screenshot review moved protocol diagnostics under source details and
  made context status readable. The first conductor browser probe also had a
  selector-string syntax error; a later screenshot pass explicitly scrolled the
  panel into view. Neither scratch-probe correction is a product failure.

## Surface completion and limits

The operation vocabulary remains at 45. This optional reader adds no mutation,
workflow flag, repair allowance or implicit interview. The API owns packet
computation and validation; the browser and CLI are consumers. CLI help and the
agent guide expose `design craft`, its stages, new-directory export, package
inspection and checking. README and WHATSNEW describe the supported behavior.
Tests cover shared logic and real CLI operations; the named browser walks prove
responsive interaction, actual downloads and freshness.

Existing operations reconcile system changes and publish attributed review
records. Opening guidance records no inspection. Existing connected-app receipts
can supply their *reported* repository, revision, build and runtime identity;
the adapter does not discover or execute that runtime. Native new-work roles,
images, external review roles and hosted/Linux native execution remain unsupported
or unverified as the compatibility matrix says. The workflow and adapter remain
opt-in. Phase 7 still owes independent output quality, participant partnership,
hosted acceptance and the rollout decision.
