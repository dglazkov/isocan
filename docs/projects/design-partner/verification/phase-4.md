## What this proves

An agent publishes comparable actual versions with an attributed recommendation,
hypothesis and tradeoff. The person can try either, choose, delegate or request
specific revision. A choice is one canonical target edit and decision comment,
with one paired Undo. Briefs and rejected alternatives remain available. Human
words, delegated rationale, native-conversation reports and independent agent
judgment have distinct authority. The writer never infers a human from an
unknown actor or fabricates an answer on behalf of an external conversation.

These are authored synthetic task examples and engineering proofs. They do not
measure generated-design quality, the usefulness of a question to real people,
or a preference uplift. Those remain phase 7's independent evidence. Selecting
an HTML prototype for a connected application leaves repository implementation
and runtime verification owed.
