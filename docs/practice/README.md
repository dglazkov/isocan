# Practice

One page a night, `YYYY-MM-DD.md`, showing where the way isocan is built
leaks, measured from the tree, git and GitHub.
[`docs/projects/practice/design.md`](../projects/practice/design.md) is the
argument.

The pages here (2 to 5 October 2026) are isocan's own practice page, written
by `scripts/practice.mjs` before it was retired. The nightly health-page series
that followed is no longer produced in this repository; git history keeps it.
The rows isocan still holds itself, like the bundle ceiling and the export
ratchets, are its own tests.
