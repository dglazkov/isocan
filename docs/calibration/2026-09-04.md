# Judge calibration — 2026-09-04

27 canvases read; **12 preference pairs** (a person keeping an earlier version while later ones existed), **30 comparisons** (the kept version against each it beat), 0 skipped.

**Agreement 12/19 = 63% · κ 0.26** against chance 0.5 (the shuffle) · $11.77 · 11 unanswered.

**A first reading, not a calibration.** 19 comparisons cannot separate a judge from a coin with any confidence (κ's standard error here is about ±0.23); the plan says a judge is *calibrated or not shipped*, and this is the harness that will say which once /variation puts more pairs in the log. What it can already show is the disagreements, one by one.

## What the first run taught

Read before the number. This run predates two rules the harness now has, and both were learned from it:

- **16 of the 30 comparisons were not a person's choice.** They were *Admiral One* — an agent — making its own earlier version current again while it worked. The plan's premise is that the version stack holds *human* labels; the harvest could not tell whose hand it was. Now `isocan evals pairs` asks the registry and says *(an agent)*, and the harness leaves those out unless `--include-agents` — but the registry calls an actor an agent only when its claim came through an agent's harness, and Admiral One drove the CLI as itself, which is a person's harness, so it still reads as a person. The honest tool for that case is `--exclude "Admiral One"`, by name, on the page. The people's choices here are Kenny's 7, Di's 3, Isaac's 2, and one each from Dion 2, Dion Almaer and *the Al*.
- **Several pairs were the same bytes.** *Badge probe*'s two PNGs share an MD5; four of the *Multiplayer fell out* comparisons differ by one line of quotation marks. A judge asked to choose between identical files buys a coin flip at $0.40; the harness now skips a pair whose two versions share a blob hash.
- **11 comparisons got no answer** — all seven of Kenny's *Lake House Tracker* pairs and four others — and this page cannot say why, because the run column (turns, seconds, how it stopped) was added to the table after this run. The likely reason is size: those are the largest screens at the home and the judge had eight turns. The next run will say.
- **Cost: $11.77 for 30**, about 40¢ a comparison — the reads, not the verdict. A judge over screenshots rather than source would be cheaper and closer to what a person saw; that is the next thing to try.

So the honest number is smaller than the headline: among comparisons a person made and the judge answered, it agreed 7 of 9. Too few to mean anything; enough to see the shape.

## Method

`isocan evals pairs` per canvas; each kept version against each version it beat at that moment; the two files fetched with `isocan get --rev` and shown to `claude -p` (Read only, up to 8 turns) as A and B in a shuffled order, asked to argue against each before picking, and to cite. Agreement is judge-pick equals person-pick; κ = 2·agreement − 1 because the shuffle makes chance a coin. Nothing is written to any canvas.
